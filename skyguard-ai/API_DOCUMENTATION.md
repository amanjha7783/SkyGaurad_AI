# SkyGuard AI: API Reference

The backend exposes a fully documented REST API via FastAPI. 
When the server is running, interactive Swagger UI documentation is automatically available at:
`http://localhost:8000/docs`

## Core Endpoints

### 1. Ingest Observation
`POST /api/observations`
Accepts new telemetry data and immediately routes it through the real-time anomaly detection pipeline.

**Payload:**
```json
{
  "station_id": "STN001",
  "timestamp": "2023-10-01T12:00:00Z",
  "temperature_c": 22.5,
  "pressure_hpa": 1012.3,
  "relative_humidity_pct": 45.0
}
```

### 2. Fetch Live Stream
`GET /api/observations`
Retrieves a paginated list of all processed observations.

### 3. Fetch Alerts
`GET /api/alerts`
Retrieves active and historical incidents generated by the Intelligent Alert Engine.

### 4. Update Alert Status
`PUT /api/alerts/{alert_id}/status`
Allows operators to acknowledge or resolve an incident.

**Payload:**
```json
{
  "status": "ACKNOWLEDGED"
}
```

### 5. Fetch Sensor Health
`GET /api/sensor-health`
Returns the latest predictive health scores (`0-100%`) for all sensors across all stations, including diagnostic reasoning (`health_reason`).

### 6. Fetch Anomalies
`GET /api/anomalies`
Returns a strict log of every individual anomalous observation explicitly flagged by the models.

### 7. Fetch Stations
`GET /api/stations`
Returns metadata and geographic coordinates for all monitored AWS locations.
